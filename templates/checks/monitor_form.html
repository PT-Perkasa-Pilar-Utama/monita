How Monita checks this URL

  1. Monita sends a GET request to the URL at the interval you choose.
  2. A check passes when the status matches the expected status within the timeout. If you set a keyword, the body must also contain it.
  3. Two failed checks in a row open an incident. The first passing check closes it.
  4. A critical monitor alerts by email and webhook. A warning monitor alerts by email only.

Monita keeps single checks for 7 days and daily summaries for good.
